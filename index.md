# Data Galactica

**A permanent ID for every person and company.** Official site: [datagalactica.com](https://datagalactica.com/)

Data Galactica is a registry of permanent identifiers for people and organisations. Every record gets a Galactica ID that never changes: DGP- for a person, DGC- for an organisation. CINs, LEIs, UK company numbers and Wikidata IDs all resolve to the same ID. Each card says what the record is, where it came from and how sure the registry is, with a grade from bronze to verified. Users can verify that a company exists and is operating, check whether there is a public record of a person in a role, find people by role and city, size a market by country, city or industry, and watch records for changes. Owners can correct, claim or remove their record. Developers and AI agents get a prepaid API with free starting credit, an MCP server and OAuth, so agents can keep a card up to date with every change reviewed.
